# 2027 AviusULD Calendar

Company holiday calendar for AviusULD Ltd. (ปฏิทินบริษัท อาวียุส ยูแอลดี จำกัด), published at
https://aviusuld-calendar-production.up.railway.app/

- `public/index.html` – the calendar page (2027, with 2026 for reference)
- `public/pdf/` – one-page print versions (A4 / A3)
- `server.js` – small static file server used by Railway (`npm start`)
